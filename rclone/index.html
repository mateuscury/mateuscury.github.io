rclone (personal)

A private Google OAuth client used with the open-source rclone command-line tool.

What it is

This OAuth client lets rclone, running on my own computer, connect to my own Google Drive account so I can back up, sync, and manage my files from the command line.

Who uses it

Only me, Mateus Furtado Cury. It is not a public product, not offered to other users, and not sold or distributed.

How it works

  • rclone runs locally on my machine and talks directly to the Google Drive API.
  • OAuth tokens are stored only in my local rclone configuration file.
  • No data passes through any server I operate. There is no backend.
