Privacy Policy

rclone (personal) · Effective October 21, 2026

"rclone (personal)" is a private Google OAuth client operated by Mateus Furtado Cury for use with the open-source rclone tool. It is used solely to access the operator's own Google Drive account.

Data accessed

With your authorization, rclone accesses Google Drive files and folders, including file names, contents, and metadata, in order to list, upload, download, sync, and manage them.

How data is used

Data is used only to perform the file operations requested on the local machine where rclone runs. It is not used for advertising, analytics, profiling, or training any model.

Storage

OAuth access and refresh tokens are stored only in the local rclone configuration file on the user's own device. Files are transferred directly between that device and Google's servers. No data is sent to, stored on, or processed by any server operated by the developer.

Sharing

Google user data is not sold, shared with, or transferred to any third party.

Google API Services User Data Policy

rclone (personal)'s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time from your Google Account at myaccount.google.com/permissions and by deleting the corresponding remote from your local rclone configuration.
